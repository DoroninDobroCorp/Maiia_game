# SUR — Мир, который ты создаёшь
## Станция на связи · живой архив

Расширение **0.4 / «Станция на связи»** реализует [ТЗ приключений и живого архива](docs/MISSION_GAMIFICATION_AND_LIVING_ARCHIVE_SPEC.md). После пролога откройте **«Вместе» → «Новая глава»**, посмотрите содержание и нажмите **«Открыть эти три приключения»**. Кнопка **«Истории» / J** ведёт к трём линиям; **«Галерея»** — к личной выставке.

- **«Голоса Южного Маяка»**: 20 конвертов, 100 испанских лексем, диалоги и игровые задания, собственный альбом.
- **«Автомат для станции»**: шесть шагов к своей отдельной игре Godot; версии исходников и проверенный запуск с выставочного терминала.
- **«Два голоса воды»**: самостоятельные речная и водопадная записи, сравнение, полевой альбом и диптих.
- Архив хранит работы и их версии; 12 мест в каждом зале, три избранных экспоната станции, новые залы и снимки выставок. Заполнение комнаты не ограничивает архив.
- Семейный редактор поддерживает восемь механик и пакеты JSON. Пример следующего приключения — «Три силуэта для новой вывески». Публикация, проверка реальных действий и запуск игры остаются отдельными решениями.

[Инструкция для семьи](docs/adventure_family_guide.md) · [Устройство и расширение](docs/adventure_developer_guide.md) · [Отчёт проверок](docs/TEST_REPORT.md).

Предыдущие возможности Phase A/B/C перечислены ниже и продолжают работать. Реальные сохранения при разработке и тестировании не сбрасываются.

**SUR** — камерная атмосферная игра на Godot 4, в которой реальные навыки, творчество и любопытство постепенно преображают личный мир, а игрок со временем становится его автором.

Текущая сборка включает завершённую **Phase A / Vertical Slice**:
- Законченная 3D-комната горной лесной станции (Эль-Больсон, Патагония);
- Интерактивные объекты с мягкой подсветкой и подсказками;
- Пролог **S00 «Это моя станция»**:
  - Настройка таблички станции (имя и символ);
  - Выбор и расстановка экспоната на рабочем столе;
  - Первая тайна станции: шкатулка с тремя дисками и поэтической уликой на крышке (ошибка без штрафа, ответ заранее не раскрывается);
  - Восстановление радиоканала и преображение мира (переход в тёплую световую стадию 2);
- Интерактивный радиоприёмник «Южный Маяк» и настенная карта долины;
- Иллюстрированный журнал станции (задачи, архив, заметки);
- Панель настроек (масштаб UI, громкость звука, режим «уменьшение движения»);
- Автономное локальное сохранение в `user://savegame.json` с атомарной записью;
- 100% офлайн-режим: никаких облачных запросов, телеметрии и сбора личных данных.

**Phase B** добавляет законченный цикл реальных экспедиций и безопасного локального авторства:
- Каталог S00–S11 и семь направлений навыков;
- Родительская консоль: утверждение и публикация точной версии задания, отзыв версии и проверка результата;
- `QuestInstance` фиксирует принятую версию: последующая редакция не меняет уже принятую экспедицию;
- «Готово» создаёт submission без XP; награда и изменение мира применяются только после взрослого подтверждения;
- Защита от повторной награды по `activity_id`, пауза/возобновление и safety hold при отзыве версии;
- Локальный архив изображений и сохранение результата независимо от внешнего исходника;
- Безопасный редактор разрешённой авторской реплики с preview / publish / rollback;
- Сохранения с атомарной записью, вращающимися резервными копиями и восстановлением повреждённого main-save;
- Финальный основной квест S10 открывает визуальный эффект обсерватории; S11 остаётся отдельной авторской задачей;
- Весь цикл остаётся полностью локальным и работает без сети и AI-ключей.

**Phase C** расширяет мир и даёт взрослому локальный редактор содержания без правки Godot-сцен:
- Встроены **24 стартовые карточки**, по 3 задания для каждого из 8 направлений навыков. Разминка больше не считается одной из главных целей Майи;
- В журнале отдельно выделены три стартовых приключения: **FG01 «100 слов в эфире»**, **FG11 «Первая своя игра»** и **FG08 «Река и водопады»**. Они по-прежнему проходят обычный взрослый lifecycle публикации;
- Растяжка оформлена отдельным спокойным ритуалом на **5 разных дней**: пропуски не сбрасывают прогресс, повторная отметка в тот же день не считается, а пятый день навсегда зажигает новый свет на станции без начисления XP;
- Станция получила реальное перемещение: ходьба вперёд/назад, поворот, стрейф и переход через существующую дверь в отдельную пристройку обсерватории с обратным выходом;
- Добавлены три места: радиокафе «Южный Маяк», пристройка мастерской и полевой архив;
- В родительской консоли можно открыть встроенную карточку как `revision + 1` или создать семейный квест с нуля;
- Импорт JSON-пакета атомарный: пакет либо проходит проверку целиком, либо не меняет сохранение; импортированные карточки всегда остаются `DRAFT` до явной публикации взрослым;
- Встроенные ревизии неизменяемы, опубликованные снимки квестов остаются замороженными, а лимиты повторов проверяются при создании экземпляра;
- Экспортируются только семейные черновики без approval/system-полей;
- Сохранения обновляются до `1.3.0`; поддержаны `1.0.0`, `1.1.0` и `1.2.0`, перед миграцией сохраняется исходная копия;
- Основная игра, квесты и редактор работают локально и без сети. Радио дополнительно получает прогноз Эль-Больсона на сегодня и завтра через Open-Meteo; при доступном локальном VibeProxy на `127.0.0.1:8318` Gemini 3.8 только переформулирует уже полученные погодные данные. При проблемах сети радио показывает «Плохая связь».
- Атлас построен как расширяемый список точек с туманом войны. На новом сохранении открыта только «Лесная станция»; остальные точки Патагонии и дальние главы видны, но закрыты.

## Требования к запуску

- **Godot Engine:** 4.7.2 Stable (официальная сборка)
- **Платформа:** macOS (Apple Silicon / Intel), Linux, Windows
- **Рендерер:** `Forward+` (на Apple Silicon используется нативный бэкенд Metal) или `Compatibility`

### Запуск игры через терминал

```bash
# Обычный интерактивный запуск
godot --path .

# Запуск с указанием разрешения
godot --path . --resolution 1280x720

# Запуск набора автотестов Phase A (сценарии A01-A07)
godot --headless --path . -s tests/test_phase_a.gd

# Приёмка Phase B (B01-B24)
godot --headless --path . --script res://tests/test_phase_b.gd

# Приёмка Phase C (C01-C20, включая под-проверки)
godot --headless --path . --script res://tests/test_phase_c.gd
```

## Управление в игре

- **Мышь (левая кнопка):** взаимодействие с объектами в комнате (табличка, шкатулка с дисками, экспонат, радио, карта, журнал).
- **Движение мыши:** мягкий кинематографический параллакс камеры (создаёт глубину между столом и окном).
- **W/S или ↑/↓:** идти вперёд / назад.
- **A/D или ←/→:** поворачиваться.
- **Q/E:** шаг в сторону.
- **Кнопка [J] или клик по блокноту:** после пролога открыть истории; прежний журнал доступен внутри.
- **Кнопка [P] или «Вместе»:** семейная панель публикации, совместной проверки и резервных копий. Прежняя консоль доступна по ссылке внизу панели.
- **Кнопка [Esc] или клик «Назад»:** выйти из приближения / закрыть модальное окно / открыть меню настроек.
- **Кнопка [🛠 Оформить]:** открыть Терминал автора для смены названия, символа и экспоната.
