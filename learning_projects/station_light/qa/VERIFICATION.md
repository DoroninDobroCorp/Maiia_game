# Проверка учебной основы

Проверено 2 октября 2026 на macOS / Apple M1, Godot `4.7.2.stable.official.ed1daf0bf`. Рендерер отдельной игры: Compatibility / OpenGL 4.1 Metal.

Команда из корня репозитория:

```sh
python3 learning_projects/station_light/tools/check.py --godot /opt/homebrew/bin/godot --screenshots
```

| Проект | Проверки GDScript | Запуск главной сцены |
| --- | --- | --- |
| Текущий 1.0 | 61 / 61 | Успешно |
| ZIP 0.1, распакованный отдельно | 58 / 58 | Успешно |
| ZIP 0.2, распакованный отдельно | 59 / 59 | Успешно |
| ZIP 0.3, распакованный отдельно | 59 / 59 | Успешно |
| ZIP 0.4, распакованный отдельно | 61 / 61 | Успешно |
| ZIP 1.0, распакованный отдельно | 61 / 61 | Успешно |
| Полный архив исходников | 61 / 61 | Успешно |

Всего 420 успешных утверждений. Godot не сообщил ошибок скриптов, загрузки или запуска. Проверены SHA-256, целостность ZIP, точное совпадение исходников архива со снимком версии и сохранённая ступень возможностей. `main.gd` и `game_state.gd` всех версий побайтно совпадают с текущими исходниками. Тесты работают на временных копиях без SUR, сервисов профиля и сохранений. Логи перенаправляются во временную папку и удаляются с ней.

Регрессия жизненного цикла: три уведомления потери фокуса отправляются сцене до `_ready()`, когда действий `light_*` ещё нет в InputMap. Направление мыши сбрасывается без ошибок отсутствующего действия. Проверка обычной потери фокуса после `_ready()` также проходит.

Запуск `tests/test_learning_game.gd` из корня SUR теперь сразу завершается с кодом 1 и выводит команду `python3 learning_projects/station_light/tools/check.py`. Без `res://game_state.gd` тест не пытается загрузить вложенную сцену и не выдаёт ложный успешный итог.

Движение проверено по скорости, диагонали, четырём границам и пересечению огонька за один длинный шаг. Сбор проверен на дубликаты и неверные/далёкие индексы. При 0–2 предметах победы нет; при 3 — один сигнал победы. Проверен второй полный цикл, сброс после частичного сбора и после победы. Сценовые проверки проверяют раскладку физических клавиш, передачу ввода в движение, mouse down/up, отпускание мыши вне кнопки, потерю фокуса, кнопку перезапуска и обработчик R.

Снимки получены отдельным скриптом `tools/capture.gd` в реальном окне Godot при программном прохождении; затем визуально просмотрены:

- `start.png`: видны цель, 0/3, ровно три огонька, герой и управление.
- `win.png`: видны 3/3, сообщение победы, три освещённых окна станции и доступная кнопка перезапуска.
- `restart.png`: побайтно совпадает с `start.png`.

Экран чистый, без обрезанного текста и перекрытых кнопок. Это автоматизированная техническая проверка основы. Совместное прохождение ребёнком и взрослым, собственное авторское изменение, регистрация запуска SUR и экспорт приложения macOS здесь не выполнялись и не утверждаются.
