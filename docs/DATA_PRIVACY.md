# Безопасность и приватность данных

1. **100% офлайн по умолчанию**
   - Приложение не выполняет HTTP-запросов, не подключается к внешним API и не отправляет телеметрию.

2. **Изоляция профиля игрока**
   - Все файлы настроек и сохранений размещаются строго в `user://` (локальная папка песочницы приложения на ОС пользователя).
   - В коде не зашиты персональные данные ребёнка (ФИО, адрес, школа, контакты).

3. **Никакого неконтролируемого ИИ**
   - На этапе A отсутствует генеративный ИИ, диалоговые боты и сбор голосовых или текстовых данных.
