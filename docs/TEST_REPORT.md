- **Рендерер:** Metal Forward+ 60 FPS стабильно на Apple Silicon M1.

- **Ошибки и падения:** 0 критических ошибок, 0 необработанных исключений.
- **Корректное завершение:** verbose-запуск с автоматическим выходом завершается без `ObjectDB leaked` и без аудио-предупреждений.
- **Офлайн-режим:** 100% автономен, 0 внешних сетевых соединений.

После последнего текстового polish-прохода основной проект дополнительно запущен нативно через Godot 4.7.2 на macOS с `gl_compatibility`; ошибок выполнения при запуске и завершении не обнаружено. Отдельно устранён хвост процедурного ambient-аудио при teardown: финальный verbose-прогон не содержит `ObjectDB leaked`. Полный автотест Phase A после этой правки снова содержит **26 успешных проверок**.

## 4. Phase B — итоговая приёмка B01–B24

`tests/test_phase_b.gd` проверяет полный локальный цикл Phase B: невидимость draft-контента, публикацию точной ревизии, замороженный `QuestInstance`, submission без XP, взрослое подтверждение, идемпотентное начисление, вехи, паузу, согласованные альтернативы, локальный архив изображений, резервные копии, валидацию пакетов, preview/publish/rollback авторской реплики, safety revoke, офлайн-цикл, разделение demo/player XP и изменений мира, а также безопасный профильный экспорт.

Финальный прогон выполнен на отдельной копии проекта с отдельным `user://`:

```bash
/opt/homebrew/bin/godot --headless --path <isolated-copy> --script res://tests/test_phase_b.gd
```

Результат: **`PHASE B: ALL PASS (25 checks)`**. В B14 тест намеренно повреждает основной JSON; сообщение `Parse JSON failed` в этом сценарии ожидаемо, после него успешно загружается проверенная резервная копия.

После последней presentation-правки отдельно повторена регрессия Phase A на другой изолированной копии: **26/26 PASS**. Финальный editor-parse также завершён без ошибок:

```bash
/opt/homebrew/bin/godot --headless --path . --editor --quit
```
