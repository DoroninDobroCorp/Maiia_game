# Правила для агентов

Единый источник правил проекта: [CLAUDE.md](CLAUDE.md). Прочитай его целиком перед работой. Главное:

1. **Связный и интересный сюжет удерживает Майю в игре.** Каждое взаимодействие должно быть в радость, а не «пощёлкать кнопочки»; новое не противоречит ансамблю героев и нити про маяк; результат виден в мире.
2. **Игра отслеживает обучение, а не учит.** В миссиях про испанский нет обязательных упражнений; статус выполнения подтверждает взрослый.
3. **Тесты только через `python3 tools/run_checks.py`.** Настоящее семейное сохранение не трогать.
4. Коммит и пуш только по просьбе владельца.
